## 一、测试用例与截图素材

### 截图总原则

- 使用**手机端浏览器**截图（小红书用户 90%+ 手机端浏览），竖屏 3:4 比例最佳
- 截图前**清空对话历史**，确保界面干净
- 每张截图聚焦**一个功能亮点**，不要一张图塞太多内容
- 保留 Laplace 的 UI 顶部 Logo 区域，增强品牌识别

### 用例 1：多条件组合筛选（封面主打）

| 项目 | 内容 |
|:-----|:-----|
| **输入** | `帮我找一下五星自充50以上的Caster` |
| **展示功能** | 自然语言 → 多条件精确筛选（职阶+星级+效果+数值） |
| **预期输出** | 从者卡片列表，标注自充百分比，卡片带头像 |
| **Hook 点** | "一句话 = 传统工具翻 10 分钟菜单" |
| **构图建议** | 截全屏（含输入框+思考过程+卡片结果），重点圈出输入的那句话和返回的从者数量 |

### 用例 2：从者深度分析 + 昵称识别

| 项目 | 内容 |
|:-----|:-----|
| **输入** | `分析下村正的技能和宝具` |
| **展示功能** | 昵称自动识别 + AI 深度分析 |
| **预期输出** | 从者卡片 + 技能逐条解析 + 优缺点总结 |
| **Hook 点** | "连'村正'这种昵称都能认，还能自动分析优缺点" |
| **构图建议** | 分两张图：第一张截输入+卡片，第二张截 AI 分析文字（Markdown 富文本渲染效果） |

### 用例 3：多效果 AND 组合查询

| 项目 | 内容 |
|:-----|:-----|
| **输入** | `有无敌且带自充的从者` |
| **展示功能** | 多效果 AND 逻辑精确匹配 |
| **预期输出** | 同时拥有无敌+自充两个效果的从者列表 |
| **Hook 点** | "两个条件一句话说完，比 Chaldea 还快" |
| **构图建议** | 截全屏含结果卡片，圈出"无敌"和"自充"两个关键词 |

### 用例 4：戴冠战攻略问答

| 项目 | 内容 |
|:-----|:-----|

### 用例 5：职阶克制查询

| 项目 | 内容 |
|:-----|:-----|
| **输入** | `克制Rider的五星从者` |

| **预期输出** | 克制 Rider 的职阶从者列表（主要是 Assassin） |

## 三、图片排版设计规范

### 封面图（最重要，决定点击率）

- **尺寸**：1080 x 1440 px（3:4 竖版，小红书推荐比例）
- **布局**：
  - 上 1/3：大字标题（3-5 个字的核心 hook）
  - 中 1/3：产品截图（带手机边框 mockup 更佳）
  - 下 1/3：副标题 + 功能亮点 tag
- **字体**：加粗黑体/思源黑体，标题 60px+，副标题 30px+
- **配色方案**：
  - 主背景：深蓝渐变 #0a0e17 → #111827（与产品 UI 一致）
  - 标题文字：白色 #ffffff
  - 强调色：天蓝 #38bdf8（产品主色调）
  - 辅助色：翠绿 #34d399（数据/数字标注）
- **避免**：纯白背景（在小红书 feed 中不醒目）、字太多、截图太小看不清

### 内容图

- **手机截图处理**：
  - 截图后加圆角（12px）+ 轻微阴影
  - 可在截图旁/下方加文字注释（如箭头指向关键信息）
  - 状态栏建议裁掉（保护隐私+更干净）
- **文字注释**：
  - 圈出关键信息用红色/天蓝色圆圈或箭头
  - 底部加一行功能说明（如"一句话 → 精确筛选 10 个从者"）

### 对比图（可选，效果很好）

- **布局**：左右分栏
  - 左侧：传统工具截图（菜单多、步骤多）
  - 右侧：Laplace 截图（一句话出结果）
  - 中间加 VS 或箭头
- **标注**：左侧标"传统方式 5 分钟"，右侧标"Laplace 2 秒"

```

```

### 引流 Tag（扩大曝光）

```
#游戏工具推荐 #AI助手 #效率工具 #手游推荐 #手游攻略
```

### 社区/情感 Tag

```
#迦勒底 #二次元 #二次元安利 #手游日常
```

### Tag 使用原则

- 每篇帖子 **10-15 个 Tag**，不要超过 20 个
- **前 3 个 Tag 最重要**（影响推荐算法），放核心关键词
- 避免无关 Tag（如 #美食 #旅行），会降低精准度
- 紧跟热点：戴冠战期间加 `#戴冠战攻略` `#FGO戴冠战`

## 五、发帖时间与节奏建议

### 最佳发帖时间

- **工作日**：12:00-13:00（午休）、20:00-22:00（晚间）
- **周末**：10:00-12:00、15:00-17:00、20:00-22:00
- FGO 有活动/戴冠战/新从者实装时的当天晚上是黄金时段

### 发帖节奏

- 首发帖用**模板 A（痛点共鸣型）**，容易引发老玩家共鸣
- 间隔 2-3 天发**模板 B（安利种草型）**，触达新受众
- 戴冠战/活动期间发**模板 C（攻略实用型）**，蹭热点流量
- 后续可根据评论区反馈，针对性地出"从者分析""效果查询"等细分内容

### 互动技巧

- 评论区主动回复，引导用户试用并晒截图
- 对"有 XX 效果的从者有哪些"之类的问题，直接用 Laplace 查询后截图回复
- 鼓励用户"评论区说你最想查什么，我帮你试"
