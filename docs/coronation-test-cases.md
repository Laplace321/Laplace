# 戴冠战功能测试案例

## 一、戴冠战配队推荐

### 测试 1：基础配队查询
- **输入**：`剑阶戴冠配队推荐`
- **预期**：返回剑阶戴冠战的完整配队推荐，包含打手、出星辅助、充能辅助、增伤辅助四个角色分类，每个分类按 S/A/B 层级排列
- **验证点**：
  - 出现宫本伊织、齐格鲁德、剑阶美杜莎等打手
  - 出现红阎魔、花嫁尼禄等充能辅助
  - 出现高文、兰陵王、恺撒等增伤/出星辅助
  - 附带 Boss 机制摘要（冠位武藏）

### 测试 2：按角色分类查询
- **输入**：`剑阶戴冠战有什么打手推荐`
- **预期**：只返回打手分类的从者推荐
- **验证点**：结果中只包含"打手"角色分类

### 测试 3：按流派查询
- **输入**：`剑阶戴冠战双宝具流怎么打`
- **预期**：返回"双宝具爆破流"的打法说明，包含优缺点
- **验证点**：出现"双宝具爆破流"相关描述

### 测试 4：未收录职阶查询
- **输入**：`弓阶戴冠配队推荐`
- **预期**：返回友好提示"弓阶戴冠战配队数据暂未收录"，并列出已收录的职阶
- **验证点**：提示信息包含"目前已收录: 剑"

## 二、戴冠战知识查询

### 测试 5：Boss 机制查询
- **输入**：`剑阶戴冠战Boss什么机制`
- **预期**：返回冠位武藏的 Boss 机制详情（特性、属性、技能机制等）
- **验证点**：包含神性、女性、混沌善等关键信息

### 测试 6：通用攻略查询
- **输入**：`戴冠战怎么打`
- **预期**：返回戴冠战通用攻略知识（如被动技能解放、冠位从者机制等）
- **验证点**：包含"被动技能解放至第3个"等通用知识

## 三、职阶校验

### 测试 7：从者职阶正确性
- **输入**：`剑阶戴冠配队推荐`
- **预期**：所有推荐的从者（有 collectionNo 的）都应该是剑阶从者
- **验证点**：不应出现非剑阶从者（如骑阶美杜莎、术阶梅林等）

## 四、前端交互

### 测试 8：Preset 快捷按钮
- **操作**：在页面上查看输入框上方的快捷标签栏
- **预期**：出现"戴冠战攻略"和"戴冠战配队"两个新的 Preset 按钮
- **验证点**：点击后自动发送对应查询

### 测试 9：帮助弹窗更新
- **操作**：点击页面右上角"说明"按钮打开帮助弹窗
- **预期**：
  - "我能帮你做什么"列表中包含"戴冠战攻略"条目
  - "试试这样问"区域出现"剑阶戴冠配队"和"戴冠战攻略"两个示例 chip
- **验证点**：点击示例 chip 后自动填入查询并关闭弹窗

### 测试 10：Greeting 消息
- **操作**：打开页面，查看初始欢迎消息
- **预期**：欢迎消息中包含戴冠战相关推荐提示

## 五、回复格式

### 测试 11：禁止表格格式
- **输入**：`剑阶戴冠配队推荐`
- **预期**：回复中不应出现 Markdown 表格格式（| --- | 之类）
- **验证点**：全部使用列表和分组展示

### 测试 12：回复篇幅
- **输入**：`剑阶戴冠配队推荐`
- **预期**：回复应控制在合理篇幅内（约 800 字），S 级从者详细说明，A/B 级简要说明
- **验证点**：不应出现超长回复导致的长时间等待
