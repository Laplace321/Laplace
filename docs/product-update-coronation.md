# Laplace 功能更新 — 戴冠战攻略系统

## 新增功能

**戴冠战配队推荐**

现在你可以直接询问 Laplace 戴冠战的配队推荐了。目前已收录 **剑阶戴冠战** 的完整攻略数据，包括：

- **打手推荐** — 按 S/A/B 三个梯度推荐适合的输出从者，标注宝具色卡、核心优势和注意事项。推荐的打手包括宫本伊织、齐格鲁德、剑阶美杜莎、千子村正、宫本武藏、红阎魔等
- **出星辅助** — 为打手提供暴击星的从者推荐，如高文、兰陵王、骑士迪昂、冲田总司等
- **充能辅助** — 帮助队友 T1 启动宝具的从者推荐，如红阎魔、花嫁尼禄、阿尔托莉雅、兰陵王等
- **增伤辅助** — 提供攻击力/宝具威力/暴击威力等增伤 buff 的从者推荐，如恺撒、高文、阿尔托莉雅 Alter、拉克什米、莫德雷德、冲田总司、柳生等
- **打法流派** — 提供"双宝具爆破流"和"EX 连击流"两种主流打法的详细说明和优缺点分析

**戴冠战知识查询**

除了配队推荐，你还可以查询戴冠战的通用知识：

- **Boss 机制** — 查询冠位武藏的特性、属性、技能机制等详细信息
- **通用攻略** — 戴冠战的基础规则说明，如被动技能解放条件、冠位从者机制等

**职阶校验保护**

系统会自动校验推荐从者的职阶是否正确，确保剑阶戴冠战只推荐剑阶从者，不会出现推荐错误职阶从者的情况。

## 使用方式

你可以这样提问：

- **"剑阶戴冠配队推荐"** — 获取完整的剑阶戴冠战配队方案
- **"剑阶戴冠战打手推荐"** — 只看打手部分
- **"剑阶戴冠战双宝具流怎么打"** — 了解特定打法流派
- **"剑阶戴冠战 Boss 什么机制"** — 查询 Boss 详情
- **"戴冠战怎么打"** — 获取通用攻略知识

也可以通过页面上方的 **"戴冠战攻略"** 和 **"戴冠战配队"** 快捷按钮一键查询。
