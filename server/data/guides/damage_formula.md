## 指令卡攻击伤害公式

```
(ATK * 0.23
  * ((指令卡伤害倍率 * (1 ± 指令卡性能BUFF ∓ 指令卡耐性)) + 首位加成)
  * 职阶补正
  * 职阶克制
  * 副属性克制
  * (1 ± 攻击力BUFF ∓ 防御力BUFF - 特防状态BUFF)
  * (1 + 暴击补正)
  * (1 + 特攻状态加成 ± 暴击威力BUFF * 暴击补正)
  * Extra攻击加成
  * 指令卡Hit倍率
  * 随机数)
± 伤害附加与减免
∓ 被伤害减免与提升
+ BusterChain加成
```

## 宝具伤害公式

```
(ATK * 0.23
  * 宝具伤害倍率
  * (指令卡伤害倍率 * (1 ± 指令卡性能BUFF ∓ 指令卡耐性))
  * 职阶补正
  * 职阶克制
  * 副属性克制
  * (1 ± 攻击力BUFF ∓ 防御力BUFF - 特防状态BUFF)
  * (1 + 特攻状态加成 ± 宝具威力BUFF)
  * 宝具特攻倍率
  * 随机数)
± 伤害附加与减免
∓ 被伤害减免与提升
```

## 伤害乘区分类

FGO 的伤害公式中，增伤 BUFF 按所在乘区可分为 A/B/C/D 四类。**同一乘区内的 BUFF 相加，不同乘区之间相乘**，因此合理搭配不同乘区的 BUFF 比堆叠同一乘区效果更好。

### A 类：指令卡性能乘区

公式位置：`指令卡伤害倍率 * (1 ± 指令卡性能BUFF ∓ 指令卡耐性)`

| BUFF 类型 | 说明 | 代表技能 |
|:---|:---|:---|
| 指令卡性能提升（魔放） | 提升特定色卡的攻击/NP获取/产星 | 蓝魔放、红魔放、绿魔放 |
| 指令卡耐性下降 | 降低敌方对特定色卡的抵抗 | 蓝耐性下降、红耐性下降 |

- 蓝魔放（Arts 性能提升）、红魔放（Buster 性能提升）、绿魔放（Quick 性能提升）均在此乘区
- 同色的魔放与耐性下降在同一乘区内相加

### B 类：攻防乘区

公式位置：`(1 ± 攻击力BUFF ∓ 防御力BUFF - 特防状态BUFF)`

| BUFF 类型 | 说明 | 代表技能 |
|:---|:---|:---|
| 攻击力提升 | 无差别提升所有攻击伤害 | 加攻、攻击力UP |
| 防御力下降 | 降低敌方防御力 | 降防、防御力DOWN |
| 特防状态 | 对特定敌人的防御 | 对〇〇特防 |

- 加攻与降防在同一乘区内相加，因此「30% 加攻 + 30% 降防」等效于 60% 的 B 类增伤
- 特防是减法，降低该乘区的总值

### C 类：特攻/暴击/宝具威力乘区

**指令卡攻击**的公式位置：`(1 + 特攻状态加成 ± 暴击威力BUFF * 暴击补正)`

**宝具攻击**的公式位置：`(1 + 特攻状态加成 ± 宝具威力BUFF)`

| BUFF 类型 | 适用场景 | 说明 |
|:---|:---|:---|
| 特攻状态（upDamage） | 指令卡 + 宝具 | 对特定特性敌人额外增伤（如对龙特攻、对混沌特攻） |
| 暴击威力提升 | 仅指令卡暴击时 | 提升暴击伤害倍率（暴击时才生效） |
| 宝具威力提升 | 仅宝具 | 提升宝具伤害倍率 |

- **特攻状态**是有条件限定的——只对拥有特定特性的敌人生效（如"对龙特攻"只对带龙特性的敌人有效）
- 暴击威力和宝具威力是无条件的，但分别只在暴击和宝具时生效
- 这三者同属 C 类乘区，相互之间是**加法关系**。例如 50% 对龙特攻 + 100% 宝具威力 = C 类总增 150%

### D 类：宝具特攻乘区（宝具独有）

公式位置：`宝具特攻倍率`（独立乘区，与 C 类相乘）

| BUFF 类型 | 说明 | 代表从者 |
|:---|:---|:---|
| 宝具特攻 | 宝具自带的对特定敌人特攻倍率 | 杰克对女性特攻、尼禄·布莱德对秩序特攻 |
| 宝具全体特攻 | 宝具自带的全体特攻 | 源赖光对魔性/天/地特攻 |

- D 类特攻是宝具自带的，写在宝具效果里，不是 BUFF 状态
- D 类与 C 类的特攻状态**相乘**而非相加，因此两者叠加时收益非常高
- 例如：C 类 50% 对龙特攻 + D 类 150% 宝具对龙特攻 = 总增 `1.5 * 2.5 = 3.75` 倍（而非简单的 200%）

## 配队增伤思路

由于不同乘区之间相乘，合理的增伤配队应该尽量覆盖多个乘区：

- **单一乘区堆叠**：50% A + 50% A = 100% → 总伤害 ×2.0
- **多乘区搭配**：50% A + 50% B = → 总伤害 `1.5 * 1.5 = 2.25`

因此，与其给一个从者堆两个 50% 加攻（B+B），不如搭配 50% 加攻 + 50% 魔放（B+A），实际增伤更高。
